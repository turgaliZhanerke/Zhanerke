# №1 Тапсырма: GitHub репозиторийін құру және клондау

Бұл жобада Git және GitHub платформасымен жұмыс істеудің негізгі қадамдары орындалды.

## Орындалған тапсырмалар тізімі:

* **GitHub аккаунтын құру**: GitHub платформасында ресми пайдаланушы аккаунты тіркелді.
* **Жаңа репозиторий ашу**: Жобаны сақтау және басқару үшін жаңа қашықтағы (remote) репозиторий құрылды.
* **README.md файлын қосу**: Жоба туралы негізгі ақпаратты сипаттау үшін осы нұсқаулық файлы жасалды.
* **Репозиторийді клондау**: Қашықтағы репозиторий `git clone` командасы арқылы жергілікті (local) компьютерге сәтті көшірілді.

## Қолданылған негізгі Git командасы:

Жобаны компьютерге жүктеу үшін келесі команда орындалды:
```bash
git clone <сіздің-репозиторий-сілтемеңіз>
